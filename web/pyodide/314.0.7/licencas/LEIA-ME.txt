Entre Nós no celular: componentes de terceiros e licenças
=========================================================

O app no navegador (PWA) roda o mesmo código Python do computador dentro do Pyodide. Os arquivos
abaixo são distribuídos junto com o site, sem modificação, cada um com a sua licença.

Pyodide 314.0.7 (pacote npm pyodide@314.0.7)
  pyodide.mjs, pyodide.asm.mjs, pyodide.asm.wasm, python_stdlib.zip, pyodide-lock.json
  Licença: Mozilla Public License 2.0 -> ../LICENSE-pyodide.txt
  Código-fonte: https://github.com/pyodide/pyodide

cryptography 47.0.0 (roda cryptography-47.0.0-cp314-abi3-pyemscripten_2026_0_wasm32.whl)
  Licença: Apache 2.0 ou BSD de 3 cláusulas, à escolha
  -> cryptography-47.0.0-LICENSE.txt, cryptography-47.0.0-LICENSE.APACHE.txt,
     cryptography-47.0.0-LICENSE.BSD.txt

cffi 2.0.0 (roda cffi-2.0.0-cp314-cp314-pyemscripten_2026_0_wasm32.whl)
  Licença: MIT -> cffi-2.0.0-LICENSE.txt (autores: cffi-2.0.0-AUTHORS.txt)

pycparser 3.0 (roda pycparser-3.0-py3-none-any.whl)
  Licença: BSD de 3 cláusulas -> pycparser-3.0-LICENSE.txt

six 1.17.0 (roda six-1.17.0-py2.py3-none-any.whl)
  Licença: MIT -> six-1.17.0-LICENSE.txt

Os arquivos de licença das rodas foram tirados de dentro de cada roda (pasta .dist-info) pelo
"python construir_web.py --licencas"; o build confere que continuam iguais.
